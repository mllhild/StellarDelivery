# Cruiser_Explorer

Cruiser-class exploration and cargo ship in the same anime/Starsector style as the frigate and destroyer, and built from the same materials.

- 181.7 m long including the bow sensor prongs, 61 m wide across the canards and 30 m tall. That is 1.9× the destroyer's 94.5 m. 1 Blender unit = 1 m.
- About 30.9k triangles (outline shells included), 229 objects under `Cruiser_Root`. Each cargo bay's containers are merged into one mesh to keep the object count low.
- Source: `Assets/Models/Cruiser_Explorer/Cruiser_Explorer.blend`. Unity: `Cruiser_Explorer.fbx` (same export settings as the others). The toon materials are set up by `ToonMaterialPostprocessor`.

## Layout
- **Forward command section:** arrowhead hull with delta wings and orange-tipped canards, twin bow sensor prongs, sensor blisters and a ventral sensor dome, and a three-tier bridge with bridge wings and a tall mast.
- **Cargo spine:** four open-frame bays holding 141 standard containers around a central spine.
- **Aft engineering section:** a large survey dish, a secondary dish and a long-range antenna array. Two side sponsons carry drone hangars, with lit guide strips, and their own engines.
- **Propulsion and defence:** six main engines plus two sponson engines, swept wings, dorsal and ventral fins, six point-defence turrets, and ventral cargo bay doors.
